# 基于RAG和低GI库的糖尿病饮食管理小程序（DPAssistant）

> 第 19 届中国大学生计算机设计大赛中南赛区一等奖作品。
> 本仓库为微信小程序前端可运行原型，完整技术方案（RAG 检索增强、知识图谱设计）与实验详见《作品报告》。

## 前期工作

本项目基于前期工作 [**FoodQuantification — 食物量化微信小程序**](https://github.com/weiyuchoumouHDF/FoodQuantification)（第 18 届中国大学生计算机设计大赛中南赛区三等奖）迭代而来。前期项目解决了"幼儿园场景下孩子饮食摄入的拍照记录"问题，本项目在此基础上进一步面向糖尿病患者，从"记录"延伸到"个性化饮食干预"。

## 项目定位

面向 2 型糖尿病患者的饮食管理小程序原型。核心思路是：用低 GI 食物知识库做基础数据支撑，用大模型做健康问答和饮食建议，帮助患者在日常饮食中做出更合理的选择。

## 已实现的功能

| 功能 | 状态 | 说明 |
|------|------|------|
| AI 健康问答 | ✅ 真实可用 | 调用 DeepSeek API（`deepseek-chat`），配置有效 Key 后可真实对话 |
| 低 GI 食物知识库 | ✅ 真实构建 | 114 种食材，含 GI 值、糖分、蛋白质、碳水、膳食纤维等字段 |
| 食物-疾病关系库 | ✅ 真实构建 | 107 条食物与疾病的关联数据 |
| 低 GI 食物替代库 | ✅ 真实构建 | 23 条低 GI 替代建议（如荞麦面替代白面条） |
| 饮食记录前端逻辑 | ✅ 完整 | 记录添加、今日糖分统计、进度条、周报展示 |
| 多页面框架 | ✅ 完整 | 首页、饮食、用药、健康监测、科普、AI 营养师、AI 问答，含自定义底部导航 |

## 原型演示 / 待完善部分

以下功能在原型中为模拟或规则演示，完整方案见作品报告中的设计：

- **食物拍照识别**：原型中为模拟演示（上传图片后展示预设识别结果），完整方案为多模态大模型识别
- **AI 营养师食谱生成**：当前为基于关键词的规则推荐（如"面条→荞麦面"），完整方案为 RAG 检索增强 + 大模型生成
- **RAG 检索增强链路**：作品报告中设计了"结构化知识图谱 + 非结构化 RAG 检索 + 大模型生成"三级增强链路，本原型暂未落地代码实现
- **知识图谱（Neo4j）**：设计方案，未在本原型中实现
- **语音输入**：原型中为模拟演示
- **用药管理 / 健康监测 / 科普文章**：页面框架已搭建，数据为演示数据

## 技术说明

- **前端**：微信小程序原生开发
- **AI 问答**：DeepSeek API（`https://api.deepseek.com/v1/chat/completions`，模型 `deepseek-chat`）
- **知识库**：自建低 GI 食物营养成分库（114 种食材）、控糖食谱案例库
- **设计方案**：RAG 检索增强 + 知识图谱（详见作品报告）

## 环境配置

| 配置项 | 位置 | 说明 |
|--------|------|------|
| 微信小程序 AppID | `project.config.json` | 替换为自己的 AppID |
| DeepSeek API Key | `pages/qa/qa.js` → `API_KEY` | 替换占位值 `'Your_API_Key'`，AI 健康问答功能需要 |

> 本原型的数据为前端模拟（`app.js` 中的 `globalData`），暂不依赖云数据库，无需配置云开发环境。

## 知识库说明

项目内置三个知识库文件（`source_db/` 目录）：

| 文件 | 内容 | 字段 |
|------|------|------|
| `food_nutrition.csv` | 低 GI 食物营养成分库（114 种食材） | `food_name`, `category`, `sugar_g`, `protein_g`, `carbs_g`, `fiber_g`, `GI` |
| `food_disease_relations.csv` | 食物-疾病关系库（107 条） | `food_name`, `disease_name`, `relation_type`（RECOMMENDED/LIMITED 等） |
| `food_substitute.csv` | 低 GI 食物替代库（23 条） | `food_from`, `food_to`, `reason` |

另有 Excel 版本（`data/` 目录）：低 GI 食物营养成分知识库.xlsx、控糖食谱案例库.xlsx。

## 快速开始

1. 克隆本项目
2. 用微信开发者工具打开，AppID 填自己的
3. 按上方"环境配置"填写 DeepSeek API Key（不填也能运行，只是 AI 问答功能不可用）
4. 预览运行

> 注意：API 密钥不应硬编码在前端，生产环境建议通过云函数或自有服务器转发。
